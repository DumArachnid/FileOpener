This site aims to provide a functional workspace for ChromeOS users, especially for educational purposes.

# Why create HTML that runs a long Base64 string?
The Base64 GitHub release enables you to run the file opener in almost any location, such as mimo.org.

Mimo.org is known for its inability to update if the code is deemed too complex. However, the Base64 code circumvents this limitation.

# Did you use AI for the README.md?
Yes, I did. I used the built-in “Apple Intelligence” that modern iPhones have, not the cloud LLM. This means I ran the AI locally instead of wasting water.
